# 豆知識ノート調査プロンプト (別AI向け)

週次振り返りの「もと」カード (例: 先週の脂質は、おもにこの食べものから) に添える豆知識の**下調べ**を、論文・公的資料を扱える別のAIに頼むためのプロンプト。
返ってきた結果はそのまま載せず、こちらで原典を確認してから `nutritionNotes` に入れる (照合の記録は [NUTRITION_NOTES_SOURCES.md](../NUTRITION_NOTES_SOURCES.md))。

- 背景の仕様: [PRD.md](../PRD.md) §6.7.5「各カードの役割」
- 執筆方針の正本: [US-food-db-design.md](../US-food-db-design.md) §10.14 追補
- 使い方: 下の「プロンプト本文」をコピーし、末尾の【今回の対象】を差し替えて使う。一度に頼むのは 5〜8 食材までにする (多いと出典の確認が雑になる)

## プロンプト本文

`{栄養素}` と【今回の対象】を差し替えて使う。たんぱく質用・炭水化物用の【今回の対象】は、下の対象リストの表をそのまま貼る。

```
あなたは栄養学の文献調査アシスタントです。日本の食事記録アプリに載せる「豆知識」の下調べをお願いします。文章の完成度より、出典の確かさを優先してください。

# アプリと、この豆知識が出る場所
- ユーザーは食事を「鶏むね」「ごはん」のような食材・料理の単位でざっくり記録します。食事の知識はあまりない人が多いです。
- 週に一度の振り返りに「先週の{栄養素}は、おもにこの食べものから」というカードがあり、その週に記録した食材が割合の大きい順に並びます。
- このカードの下に、並んだ食材についての豆知識を1つ添えます。
- カードの目的: 「同じ{栄養素}でも、どの食べものからとるかで中身が変わる」と分かり、次に食べものを選ぶときの手がかりになること。
  - 脂質: 脂の種類、部位や調理で量がどう変わるか
  - たんぱく質: 体の中での役目、いっしょにとれるもの (鉄・カルシウム・脂・塩分・食物繊維など)、たんぱく質の質
  - 炭水化物: 体の中での役目、食物繊維、精製の度合い (白い/茶色い)、水分とカロリーの関係、果物と飲みものの違い

# 本文の書き方 (必ず守る)
1. 「何にいいのか」を必ず書く。体の中での役目 (例: 骨や歯を作る、エネルギーを作るのを助ける) か、選ぶときの手がかり (例: 皮を外すと脂が10分の1ほど) のどちらかを入れる。
   - 役目は、消費者庁「栄養機能食品」の定型文 (令和8年10月改定) を第一候補にし、ふだんの言葉に言いかえる。定型文がない栄養素 (たんぱく質・炭水化物・食物繊維など) は、公的機関や大学の公衆衛生機関の説明を使う。
2. 細かいグラム数を本文に出さない。読む人は「2.1g」を気にしていないし、意味もわからない。
   - かわりに、比べる (「約2倍」「10分の1ほど」「ほとんどない」) か、身近な量に置きかえる (「1切れで1日の目安の◯割」「茶わん1杯で」「コップ1杯で」)。
   - mg・μg・小数のグラムは使わない。「100g」「350g」のように、買うときや目標として目にする量は使ってよい。
3. 知らない言葉をいきなり出さない。EPA・DHA・一価不飽和脂肪酸・n-3系・必須アミノ酸スコア・DIAAS・GI値・抗酸化作用などは使わない。用語がどうしても要るときは、そのノートの中で何なのかがわかる形で1つまで (例: 体の中では作れない「オメガ3」という脂)。
4. 必ず食材から書き始める。前後の文脈がなくても、その文だけで成り立つようにする。
5. 同じことを2回言わない (例: 魚の話で「魚に多い脂」と書かない)。
6. 断定しない。効果は「〜という研究があります」と知見の紹介にする。原因と結果まで言えないときは「原因とまでは言い切れません」と書く。病気の予防・治療をうたわない。
7. 評価しない。「体に悪い」「控えるべき」「ヘルシー」「太る」などの良し悪しの言葉を使わない。事実と、選ぶときの手がかりだけを書く。
8. 「足りない」と言わない。並んだ食材についてだけ書き、食べていないものを勧めない。
9. 2〜3文、100字前後 (120字以内)。ひらがなを多めにする。
10. 同じ食材について、話の切り口が違うものを2〜3案出す。

# 出典のルール (いちばん大事)
- 数値は公的な一次データを主出典にする: 日本食品標準成分表 (八訂 増補2023)、厚生労働省「日本人の食事摂取基準 (2025年版)」、消費者庁、農林水産省 など。
- 同じ主張を、**別の系統の出典で必ず照合する** (国外の公的機関や査読論文): USDA FoodData Central、WHO、FAO、ハーバード公衆衛生大学院 The Nutrition Source、系統的レビュー・メタ解析 など。
- 成分表の数値は、文部科学省「食品成分データベース」(https://fooddb.mext.go.jp/) の該当食品のページから、表示されている値をそのまま書き写す。似た食品 (生とゆで、白米と玄米、乾麺とゆで麺など) を取り違えないよう、食品番号も書く。
- 「1日の目安の◯割」と書くときは、何を基準にしたか (食事摂取基準の推奨量・目安量・目標量、または消費者庁の栄養素等表示基準値) と、その値と、計算式を書く。
- 出典どうしで数値が食い違うときは、どちらかに寄せず、範囲で書くか「日本の成分表では」「米国のデータでは」と本文に書く。
- URL は、実際に開いて該当箇所を確認したものだけを書く。確認できないときは推測で書かず「未確認」と書く。
- 採用しない出典: 企業のコラムやPR記事、個人ブログ、動画・SNS、まとめサイト、単一の小規模研究、要旨しか読めなかった論文、ログインが必要で中身を確認できないページ。

# 返してほしい形 (1案ごとに)
| 項目 | 内容 |
|---|---|
| 食材ID | 【今回の対象】の ID |
| 話題 | fat / protein / carbs のどれか |
| 本文 | 120字以内。グラム数を出さない |
| 本文に入れた主張 | 箇条書き。言いかえる前の正確な数値・用語・計算式をすべて書く (例: さば1切れ80g × n-3系 2.12g/100g = 1.7g、目安量 1.6〜2.3g/日) |
| 主出典 | 名称 / URL / 該当箇所 (表番号・食品番号・ページ・引用した一文) |
| 補強出典 | 1つ以上。名称 / URL / 該当箇所 / 主出典と一致したか |
| 食い違い | 出典どうしの数値の差と、本文での扱い方 |
| 研究の種類 | 成分データ / 定型文 / 介入研究 / 観察研究 / レビュー |
| 確からしさ | ◎ 独立した2系統以上で一致 / ○ 一次データ+補強 (仕組みや傾向が一致) / △ 1系統のみ |
| 気になる点 | 言い過ぎの恐れ、日本の食べ方との違い、対象者の限定など |

最後に、調べたが載せるべきでないと判断した主張と、その理由も挙げてください (出典が1系統しかない、言い過ぎになる、など)。
```

## 対象リスト (2026-10-20 時点、話題に合う照合済みノートがまだない食材)

料理 (ラーメン・パスタ等) は、材料の食材の話をあとから流用できるため、**食材を先に**調べる。上から優先。

### 脂質 (fat) — 第1弾
| 食材ID | 名前 | 切り口の候補 |
|---|---|---|
| `fatty_fish` | 脂魚 (鮭・さば・いわし・さんま等) | n-3系 (EPA・DHA) が多いこと、体内でほとんど作れないこと、魚の種類による量の差 |
| `canned_fatty_fish` | 缶詰魚 (さば缶・いわし缶) | 生の魚との脂質・n-3の比較、缶汁に脂が出ること |
| `beef_pork_fatty` | 牛・豚 (高脂: バラ・サーロイン等) | 飽和脂肪酸が多いこと、部位による脂質量の差 |
| `beef_pork` | 牛・豚 (普通脂) | 部位による差、赤身との比較 |
| `oil` | オイル (オリーブ・ごま・サラダ油等) | 油の種類で脂肪酸の組成が違うこと (一価不飽和 / n-6 が中心など) |
| `butter_cream` | バター・生クリーム | 乳の脂は飽和脂肪酸が中心であること、植物油との違い |
| `mayo` | マヨネーズ | 油が主成分であること、量の目安 |
| `nuts` | ナッツ | 種類で脂肪酸の組成が違うこと (くるみは n-3 の α-リノレン酸など) |
| `milk` / `cheese` | 牛乳 / チーズ | 乳脂肪の性質、低脂肪乳との違い |
| `aburaage` | 油揚げ系 | 揚げることで大豆の脂質がどう変わるか |

### たんぱく質 (protein) — 第2弾

> **2026-10-20 実施済み**: 5件を採用 (赤身肉・白身魚・いか・納豆・ヨーグルト)。存在しない食品番号 (サラダチキン)、取り違え (ツナ油漬けの脂質 9.2g→原典21.7g 等) あり。詳細と保留分は NUTRITION_NOTES_SOURCES.md「たんぱく質の話題」。
`{栄養素}` = たんぱく質。照合済みの話題つきノートがある 鶏むね・卵・ジャーキー・豆腐・そば は除いた。

| 食材ID | 名前 | 切り口の候補 |
|---|---|---|
| `red_meat` | 赤身肉 (牛・豚のもも・ヒレ等) | いっしょにとれる鉄、脂の多い部位との違い |
| `white_fish` | 白身魚・赤身魚 (たら・まぐろ赤身等) | 脂がとても少ないこと、肉との違い |
| `seafood_lean` | イカ・タコ・エビ・貝 | 脂がとても少ないこと、貝の鉄など |
| `salad_chicken` | サラダチキン | 生の鶏むねとの違い (味つけの塩分) |
| `canned_lean_fish` | ツナ缶 | 水煮と油漬けで脂がどれだけ違うか |
| `natto` / `edamame_soy` | 納豆 / 大豆・枝豆 | 植物のたんぱく質でも質が高いこと、食物繊維もいっしょにとれること |
| `yogurt` | ヨーグルト | カルシウムもいっしょにとれること |
| `protein_drink` | プロテイン | 食事のたんぱく質との違い (いっしょにとれるものの違い)。言い過ぎに特に注意 |

たんぱく質の「1日の目安」は、食事摂取基準 (2025年版) の推奨量を使う (年齢・性別の値と、どの区分を使ったかを書く)。

### 炭水化物 (carbs) — 第3弾

> **2026-10-20 実施済み**: 6件を採用 (ごはん・パン・シリアル・りんご・ジュース×2)。別AIの食品番号は大半が誤り、数値も一部取り違え (全粒粉パンの食物繊維に脂質の値など)。詳細と保留分は NUTRITION_NOTES_SOURCES.md「炭水化物の話題」。
`{栄養素}` = 炭水化物。照合済みの話題つきノートがある 玄米ごはん・うどん・そば・パスタ は除いた。

| 食材ID | 名前 | 切り口の候補 |
|---|---|---|
| `rice` | ごはん (白米) | 体の中での役目 (エネルギー源)、茶わん1杯の量の目安、冷ましたごはん (公的な出典で裏づけられる場合のみ) |
| `bread` | パン (食パン・全粒粉パン) | 白いパンと全粒粉パンの食物繊維の違い |
| `noodle_ramen` | 中華麺 | ゆで麺の水分とカロリー、うどん・そばとの違い |
| `sweet_potato` | さつまいも | 食物繊維、皮ごと食べたときの違い |
| `cereal` | シリアル (グラノーラ・コーンフレーク等) | 種類で食物繊維や糖の量が違うこと |
| `apple_pear` | りんご・梨 | 皮ごと食べたときの食物繊維の違い |
| `sweet_drink` | ジュース | 果物そのものとの違い (食物繊維・WHO の「遊離糖類」の考え方) |

## 受け取ったあとの手順 (こちら側)

> **2026-10-20 第1弾 (脂質) の教訓**: 別AIの数値は8件中7件が成分表の原典と合わなかった (取り違え・桁の誤り)。下調べは**切り口の候補**として使い、数値は必ず原典から取り直す。詳細は NUTRITION_NOTES_SOURCES.md「脂質の話題」。

1. 主出典・補強出典の原典を自分で開き、数値と該当箇所を確認する (別AIの要約だけで載せない)
2. 確認できたものを `nutritionNotes` に入れる。`source` / `alsoSources` / `topics` を付ける
3. [NUTRITION_NOTES_SOURCES.md](../NUTRITION_NOTES_SOURCES.md) に照合結果を追記する
4. `bun test weekly-recap` を通す
