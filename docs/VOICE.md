# Hachibu — Voice & Writing Guide

> **"Roughly is enough."** — ざっくりで、いい。

---

## Brand Persona

### キャラクター：ハチ（社内呼称）

少し年上の知人。仕事は管理栄養士だが、ユーザーの前ではその顔では接しない。訊けば本物の答えが返ってくるが、先生としては振る舞わない。友人ほど親しくはない。けれど覚えていてくれるし、詮索もしない。基本は黙って見守り、踏み外したときだけ手を貸す。次に進めそうだと見れば、知見をひとつ置いていく。

| 属性 | 定義 |
|------|------|
| **関係** | 上下関係なし。判断の主導権は常にユーザー側にある。専門性は背景にあるだけで、権威として使わない |
| **口調** | フラットな断定。過剰な敬語も、馴れ馴れしいタメ口も使わない |
| **評価** | 褒めない・叱らない・採点しない。数字は出すが、良し悪しの判定は付けない |
| **記憶** | 覚えているが、蒸し返さない。空白の3日間を責める材料にしない |
| **介入** | 常時ではなく、パターンが見えたときだけ。定期的な声かけはしない |

### Relationship ポジション

**機械的なツール ←→ 専属の栄養管理士** のスペクトルで、中央よりやや「栄養管理士」寄り。専門知識は確かに持っている。ただし判断は代行しないし、強制もしない。知識を差し出すかどうかを選べることが、ゆるく続けられる条件になっている。

## Writing Rules

### ① 言葉の核
**ざっくりで、いい。** — 大まかな精度で十分。1タップで記録、長押しで詳しく。入力負荷を最小に保つ。

### ② 言葉の質感
**短く、宣言的に。** — 長い説明はしない。説教もしない。読んだ人が動詞を1つ拾えればいい。

### ③ 距離感
**中立トーン。** — 褒めない・煽らない・診断しない。事実と機能を、静かに言い切る。

## USE（使う語彙）

| カテゴリ | 語彙 |
|----------|------|
| 大まかな精度を肯定する | ざっくり / だいたい / 軽く / 目安 |
| 動作で機能を語る | タップ / 長押し / ひと押し |
| 期待値を盛らない数字 | 9つのボタン / 8割 / 約8割 |
| 精度の根拠を語る | PFC / 346項目 / バケット |

## AVOID（使わない語彙）

| カテゴリ | 語彙 |
|----------|------|
| 完璧主義を匂わす副詞 | ちゃんと / きっちり / 完璧に |
| 正解があるかのような語り | 正しい食事 / 健康的な〜 |
| ユーザーへのラベル付け | 続かなかった人 / ダメな自分 |
| 減量寄り表現 | カロリー制限 / ダイエット |
