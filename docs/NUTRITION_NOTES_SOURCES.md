# 豆知識 (nutritionNotes) 出典の照合記録

週次振り返りに出る「豆知識」の根拠を、**どの主張を・どの出典で・どこまで確認したか**を残す台帳。
方針の正本は [US-food-db-design.md](./US-food-db-design.md) §10.14 追補。ここは「実際に確認した結果」の記録。

## 原則 (2026-09-29 制定)

1. **数値は公的な一次データを主出典にする** (日本食品標準成分表・厚労省・農水省 など)。
2. **別系統の出典で必ず照合する** (国内の別機関・査読論文・WHO/USDA など国外機関)。コード上は `alsoSources`。料理の豆知識は、`alsoSources` が空だとテストで落ちる。
3. **出典どうしで数値が食い違うときは、範囲で書くか、どの出典の値かを本文に明記する。** どれか1つに寄せない。
4. **原典に当たれなかったものは出典にしない。** 検索結果の要約や、ログイン認証に飛ばされるページは使わない。
5. **観察研究は「原因と結果までは分からない」と本文に書く。** 断定しない (薬機法配慮)。
6. **切り口が偏らないようにする。** 食塩の話は料理の豆知識の3割以下 (テストで担保)。

## 言葉のやさしさで書き直し — 2026-10-20

表示中のノートを、食事の知識が浅い人でもわかる言葉に書き直した (ルールは [VOICE.md](./VOICE.md)「豆知識の書き方」)。主張と出典は変えず、言葉と数字の見せ方だけを変えた。
- 用語を言いかえ: EPA・DHA / n-3系 → 魚に多い脂（オメガ3）、一価・多価不飽和 → 使わない、DIAAS → 体で作れない成分（必須アミノ酸）のバランス、抗酸化作用 → 削除 (定型文の「皮膚や粘膜の健康」の部分は残す)、総死亡 → 亡くなった人の割合、食塩相当量 → 塩分
- 数字を2つまでに: 比較は倍率に直した。倍率は原典の値から計算 (玄米 マグネシウム 49/7=7倍・B1 0.16/0.02=8倍、納豆のビタミンK 600/7=86倍→「80倍以上」、豆乳のカルシウム 31/110→「3分の1以下」、ジャーキー たんぱく質 54.8/16.5=3.3倍・塩分 4.8/0.1=48倍→「40倍以上」、そば/うどん たんぱく質1.8倍・食物繊維2.2倍→「約2倍」、さば/鮭 オメガ3 成分表2.3倍・USDA(EPA+DPA+DHA)3.6倍→「2〜4倍」)
- 「オメガ3」と書く文の数値は、EPA+DHAではなく n-3系の合計にそろえた (まさば生 2.12g・さば水煮缶 2.73g)
- 飽和脂肪酸の目標 7%エネルギー → 2,000kcalなら約16g (2,000×0.07÷9=15.6g)

### 2回目の書き直し (同日) — グラムを出さず「何にいいか」を書く

ユーザー指摘「EPAと言われてもわからない」「オメガ3が何にいいのかわからない」「誰も細かいgなんて気にしてない」を受けて、グラム数を比較・身近な量に置きかえ、役目を書き足した。新たに確認した出典と、置きかえの計算:
- **栄養機能食品の定型文 (消費者庁、令和8年10月改定)**: リーフレット PDF で原文確認。ビタミンC は「コラーゲン合成を助ける」「鉄の吸収を助ける」「抗酸化作用により細胞を保護するのを助ける」、ビタミンK は「正常な血液凝固を助ける」「骨を作るのを助ける」、マグネシウム・ビタミンB1 は「エネルギーを作るのを助ける」、カリウムは「血圧を正常に保つのを助ける」、カルシウムは「骨や歯を作るのに必要」、鉄は「赤血球を作るのに必要」。旧ノートの文言 (改定前) を改定後に合わせた。カルシウムの栄養素等表示基準値 700mg もこの資料
- **オメガ3が何にいいか**: 国立がん研究センター JPHC (約4万人・約11年、食事からのEPA・DHAが最も多い群で虚血性心疾患 約4割低い。著者は生活習慣の影響の可能性を指摘) + ハーバード (魚を週1回ほど食べる食事は心血管病を防ぐ方向・サプリでは同じ結果なし)。本文は「研究があります」「原因とまでは言い切れません」とした
- **オメガ3の1日の目安**: 食事摂取基準2025 (農水省の表) 成人 1.6〜2.3g。さば1切れ (アプリの「1切」80g) × 2.12g/100g = 1.7g →「1日にとりたい量の目安くらい」。くるみ ひとつかみ (アプリの「一掴み」15g) × 8.96g/100g = 1.3g →「半分以上」
